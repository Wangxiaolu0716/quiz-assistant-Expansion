## 五、这轮做了什么

### 1. 答题风格可选

`AnswerMode` 两个值：

- `ANSWER`（默认）：只输出答案，一行，最多 12 字。悬浮窗只显示第一行。
- `BRIEF`：答案 + 一行依据（≤20 字），悬浮窗显示两行。

系统提示词拆成「推理指引」+「输出契约」两块，契约按模式拼。远程下发的提示词也会被追加契约，所以后台改提示词不会破坏格式约束。

`OverlayController` 额外做了一道保险：不管模型返回多少行，`ANSWER` 模式只取第一行（≤60 字），`BRIEF` 取前两行，并剥掉「答案：」「解析：」前缀。

### 2. 界面重做

- 顶部深色 Header（版本号 + 状态点 + 标题 + 副标题）
- 三段 Tab：模型 / 答题 / 启动，避免一屏塞 7 张卡
- 卡片圆角 18、细边框、无重阴影
- 底部固定操作栏：`授权截图` + `启动悬浮窗`（主按钮）
- 配色：近黑主色 + teal 强调，弱化原版的蓝紫渐变

### 3. 左滑返回

`SwipeBackBox`：从左往右拖，页面跟手位移并轻微缩放，松手超过 38% 宽度就返回，否则回弹。配合 `AnimatedContent` 的滑入/滑出转场，从赞助页回设置页时生效。

### 4. 后台改皮

深色顶栏 + 浅灰背景 + 白卡片，Tab 胶囊化，按钮收敛成主/次两档。功能一个没动。

### 5. 修了配置不同步

根因：`refresh()` 里原本有 6 小时 TTL 短路，后台改完文案客户端根本不发请求。现在改成每次启动必发一次带 `If-None-Match` 的请求，304 只更新时间戳，5 秒内重复调用才防抖。

### 6. 发版链路

- 后台上传 APK（裸字节流 + 边收边算 sha256）→ 自动回填直链和哈希
- `tools/upload_feijipan.py` 上传网盘（照课表项目的 `upload_feijipan.ps1` 实现）
- 两个下载源都配好了：网盘为主、直链兜底

## 六、题库自适应解析（2.5.8）

文件：`app/src/main/java/com/quizassist/questionbank/QuestionBankModels.kt`

导入时不再看扩展名，统一交给 `QuestionBankParser.parseAuto()`：

1. 以 `[` 或 `{` 开头 → JSON
2. 前 12 行里某种分隔符能切成一致的 ≥2 列 → 表格（制表符 → 逗号 → 竖线 → 分号）
3. 都不行 → 纯文本（`题目：`/`答案：` 成块，或两行一组）

列角色：

- 有表头：按关键词找（题目/题干/问题/question、答案/answer、选项/options），列顺序无所谓
- 无表头：打分猜——越短的越像答案（`A`/`正确`/`√`），越长越像题干
- 选项列（或长得像 `A.xxx B.xxx` 的列）拼进题干，匹配和模型都能用上

**踩过的坑**：表头关键词里有单字母 `a` / `q`，最初用「包含」判断，
`A.派蒙 B.钟离 C.安柏 D.凯亚` 这种选项串被当成表头，整表按表头规则解析、答案列取错。
现在：长度 ≤2 的关键词必须完全相等，且表头单元格限长 12 字。
自测覆盖 7 种排法（带/不带表头 × 2/3 列 × 列顺序互换 × 制表符 × 判断题），全部取对。
