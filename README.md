# 答题助手 QuizAssist

Android 截图答题工具。系统截图 → 本地 OCR → 你配置的 AI 接口 → 悬浮窗显示答案。

不做自动点击、不读内存、不抓包。就是一个更快的「问 AI」。

## 功能

- **截图答题**：悬浮窗一键截图，OCR 提取题干，AI 出答案
- **两种回答风格**：只要答案（默认，一行）/ 答案 + 一句依据
- **本地题库**：导入后先查题库，命中直接返回，不花 token
- **联网检索**：遇到作品名、角色名、版本号这类需要查证的题，可开启
- **答题记录**：本地保存最近若干条，可随时翻看
- **远程配置**：公告、版本更新、提示词都由服务器下发，不用重新发版

## 题库格式：随便你怎么排，自己认

把文件准备好（`.csv` / `.txt` / `.json` 都行），在「答题 → 本地题库 → 导入题库」选它。

### 表格：带表头（推荐）

```
题目,选项,答案
"以下哪个是《原神》的五星角色？","A.派蒙 B.钟离 C.安柏 D.凯亚",B
```

也认这些表头写法：

| 列角色 | 认得的表头 |
| --- | --- |
| 题目 | `题目` `题干` `问题` `试题` `content` `question` |
| 答案 | `答案` `正确答案` `结果` `answer` |
| 选项 | `选项` `options` `choices` |

**两列**（题目 + 答案）、**三列**（题目 + 选项 + 答案）都可以，列顺序也不强求——会按表头关键词找。

### 表格：不带表头

也能认。两列默认「左题右答」；三列以上会用打分法猜：

- 越短的越像答案（`A`、`B,C`、`正确`、`√`）
- 越长的、带问号或括号的越像题干
- 中间那列如果长得像 `A.xxx B.xxx C.xxx`，会拼进题干

### 分隔符

逗号 `,`、制表符（**从 Excel / WPS 直接复制粘贴进 .txt 就行**）、竖线 `|`、分号 `;` 都能识别，自动判断。

### 纯文本

```
题目：以下哪个是《原神》的五星角色？
答案：B

题目：地球到月球的平均距离约为
答案：38 万公里
```

或者干脆两行一组、不带任何标记也行。

### JSON

```json
[
  { "question": "题干", "answer": "A" },
  { "question": "题干2", "answer": "B" }
]
```

顶层也可以是 `{ "questions": [...] }` 或 `{ "data": [...] }`。

导入成功后会提示识别到的格式和列角色，比如「已识别 CSV（逗号）（题目 / 选项 / 答案），导入 1234 道」。识别不对就说明文件排得太随意，加个表头最省事。

## 使用步骤

1. **填接口**：设置 → 模型 → 选预设或手填 `baseUrl` / `key` / 模型名（任何兼容 OpenAI 的服务都行）
2. **给权限**：设置 → 启动 → 「悬浮窗权限」和「授权截图」各点一次
3. **启动**：底部「启动悬浮窗」，回到你要答题的 App，点悬浮窗截图
4. **看答案**：答案直接显示在悬浮窗上，只给答案时是一行

答案风格随时能在「模型 → 回答风格」里切换，改完立即生效。

## 说明

本软件只通过屏幕截图和本地 OCR 获取屏幕上的文字，不使用无障碍服务、不读取其他应用内存、不抓包，也不提供自动点击或自动提交答案的功能。

它的定位和手机自带的「识屏」、系统的屏幕共享差不多：把你看到的题目更快地问给 AI。
